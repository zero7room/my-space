# Client · 客户端(Web 应用)

> 上级文档:[architecture.md](../architecture.md) · 对应 requirements §15

## 1. 产品定位

不是传统股票信息聚合站,而是**研究助手 + 主动哨兵**。两条主线:

- **同步线**:用户在 Chat 中带着具体问题与系统对话,调动所有 Skill / Tool 做分析。
- **异步线**:用户在策略页配置 Skill 调度,系统按规则跑,命中后通过主页和铃铛推送。

所有研究产物以 **Artifact** 为一等公民,可寻址、可分享、可回看,跨页面流转。

## 2. 顶部导航

```
[Logo]   主页    Chat    分析    策略              [🔔 铃铛]   [⚙️ 设置]
```

四个页面职责正交:

| 页面 | 心智 | 用户动作 | 系统状态 |
|---|---|---|---|
| **主页** | 今日工作台 | 浏览、点击展开 | 被动消费 |
| **Chat** | 研究对话 | 提问、追问 | 同步响应 |
| **分析** | 沉浸式画像 | 选 subject、切 tab | 结构化展开 |
| **策略** | 配置后台 | 配规则、管 Skill | 静态配置 |

## 3. 主页 · Home

**内容组织(混合布局)**:

```
┌──────────────────────────────────────────────────┐
│ 今日要点(时间倒序)                                │
│ ─────────────────────────────────────────────│
│ 🔴 09:35  光模块综合分变动 +0.07 → 中际旭创领跑   │ ← 点击进 chat thread
│ 🟡 09:28  英伟达盘后跌 4%,关注算力链            │
│ 🟢 08:55  光模块订单数据更新                      │
│                                                   │
│ ─── 我关注的板块 ───                              │
│ ┌─────────┐ ┌─────────┐ ┌─────────┐            │
│ │光模块   │ │军工      │ │创新药    │            │
│ │ +2.1%   │ │ -0.4%   │ │ +0.8%   │            │
│ │ 龙头:旭创│ │龙头:中航│ │龙头:恒瑞│            │
│ └─────────┘ └─────────┘ └─────────┘            │
│                                                   │
│ ─── 我关注的个股 ───                              │
│ [茅台 ↗]  [中际旭创 ↗]  [立讯精密 ↗]            │
│                                                   │
│ ─── 持续观察(策略静默期)───                      │
│ • 美债 10Y 距离阈值 4.5% 还差 +0.3%               │
│ • 北向资金 5 日累计 -42 亿(阈值 -50 亿)         │
└──────────────────────────────────────────────────┘
```

**关键交互**:

- 每条今日要点 = 一条 `Alert`,点击 → 跳转 Chat 对应 thread(如果策略配了 `open_chat: true`)或弹出 Artifact 全屏。
- 板块/个股迷你卡 = `latest.json` 的简化态,点击 → 跳转分析页对应 subject。
- 持续观察 = 策略尚未命中但接近阈值的清单,提供"接近触发"的预期感。仅展示**阈值类策略**(metric `>=` / `<=` / `changed_by` 等可计算"距离"的运算符);事件流类策略(`within(window): event...`)无定义"距离",不进入持续观察。

**新用户态**:主页空时引导 onboarding——推荐默认观察组(沪深 300 龙头、几个热门板块)+ 跳到 Chat 询问"你最关注什么"。

## 4. Chat · 对话

**单页结构**:

```
┌──────────┬────────────────────────────────────┐
│ + 新对话  │  Thread: 光模块龙头讨论              │
│ ────── │  ───────────────────────────────  │
│ 📌 光模块 │  [system] 09:35 提醒 触发开启对话    │
│ 📌 军工 ● │  ┌─Artifact 卡片──────────────┐   │
│ 半导体    │  │ 五维评分雷达图              │   │
│ 历史 ...  │  │ 中际旭创 0.86  +0.04        │   │
│           │  │ [展开 evidence] [全屏]      │   │
│           │  └────────────────────────────┘   │
│           │  [user] 为什么综合分上升?           │
│           │  [assistant] [Artifact 卡片]       │
│           │                                     │
│           │  ┌────────────────────────────┐   │
│           │  │ 输入...     [💾保存为策略]  │   │
│           │  └────────────────────────────┘   │
└──────────┴────────────────────────────────────┘
```

**多 thread 模型**:

- 左侧 thread 列表(类 ChatGPT),可命名、置顶、加标签。
- Thread 不只是聊天记录,是**研究档案**——支持收藏、分享、导出。
- 提醒触发自动新建 thread,首条 system 消息携带 Artifact 卡片。
- Thread 可以围绕 subject(板块/个股/事件),也可以是自由探索。

**Artifact 内联渲染**:

- `summary` + `highlights` 直接以富卡片展示。
- `charts[]` 用 ECharts / Cytoscape 直接画在 chat 流里。
- `conclusions[]` 每条带色标(🟢 fact / 🟡 statistical / 🔵 inferred)+ 置信度小条 + 可展开的 evidence 列表。
- 重视图(产业链图、跨市场影响图)默认折叠预览,点"全屏"打开 `/artifacts/{run_id}` 路由,可分享。

**Skill / Tool 暴露**:

- Chat 能调所有 Skill 和 Tool;由 LLMGateway 的 function-calling 自主决策调用。
- 用户可显式 `/skill 龙头识别` 触发指定 Skill。
- 调用过程在 chat 中以"思考链"形式可折叠展开。

**保存为策略**(关键打通点):

- 任何 thread 右下角有"💾 保存为策略"。
- 系统读取该 thread 的最近一次提问 + Skill 调用,LLM 转成策略 DSL 草稿。
- 跳转策略页的"新建策略"表单,DSL 已预填,用户确认/微调后启用。

## 5. 分析 · Analysis

四段 tab:**大盘 / 板块 / 个股 / 事件**。

每段都是"沉浸式 Subject Page",布局统一但内容按 subject 类型分化。

### 5.1 通用 Subject Page 骨架

```
┌─────────────────────────────────────────────┐
│ [面包屑] 板块 > 光模块                         │
│ 标题区:名称 + 关键指标条                      │
│ ───────────────────────────────────────  │
│ Tabs: 概览 | 成员/龙头 | 产业链 | 事件流 |    │
│       AI 解读 | 历史提醒 | Artifact 历史      │
│ ───────────────────────────────────────  │
│ [当前 tab 内容,模块化卡片]                    │
└─────────────────────────────────────────────┘
[侧边浮动按钮: 在 Chat 中追问 ↗]
```

### 5.2 各段差异

| Tab | 大盘 | 板块 | 个股 | 事件 |
|---|---|---|---|---|
| 概览 | 指数+宽度+情绪 | 涨跌+资金+热度 | K线+核心财务+所属板块 | 事件摘要+影响范围 |
| 主体内容 | 行业轮动 / 资金流 | 成员表 + 龙头榜 + 产业链图 | 基本面 + 技术面 + 评分 | 受益/承压清单 + 跨市场影响图 |
| 特色 tab | 资金流向、北向 | 龙头评分拆解、风险 | 长期价值评估、所属链路 | 影响路径图、相似事件 |

### 5.3 与 Chat 的桥

- 任意分析页右上角浮动按钮 **"在 Chat 中追问"**,带当前 subject 上下文新建 thread。
- Chat 中讨论某 subject 时,Artifact 卡片有 **"打开完整分析页"** 链接。
- 这两个桥让两边不孤立,用户可以在"自由探索"和"系统化研究"之间随时切换。

### 5.4 评分历史与 Artifact 时间轴

- 个股/板块的"评分趋势"读取 `leader_score` 历史快照,而非当前快照。**默认仅展示当前 `weight_template_version` 的链路**;模板切换时新版本以 `baseline=true` 起点新建一条趋势,旧版本作为灰色历史折叠展示,避免视觉断档误读为评分跳变。详见 [orchestration §3.4](./orchestration-layer.md#34-版本化指标的比较语义)。
- "Artifact 历史"tab 列出所有针对该 subject 的 Skill Run,按时间倒序;点击进入历史 Artifact 视图。

## 6. 策略 · Strategy

两个 tab:**我的策略/任务** 和 **Skill 库**。

### 6.1 我的策略/任务

```
┌──────────────────────────────────────────────┐
│  + 新建策略(用自然语言描述...)                 │
│  ──────────────────────────────────────  │
│  ▸ 光模块龙头日变动                            │
│    skill: 龙头识别 · 每日 09:35 · Δ ≥ 0.05    │
│    ✅ 启用 · 今日 1 次命中 · 7 日 12 次        │
│                                                │
│  ▸ 美债 10Y 突破                               │
│    skill: 阈值监控 · 实时 · ≥ 4.5%            │
│    ⏸ 暂停 · 7 日未命中                         │
│                                                │
│  ▸ 北向资金单日净卖出 50 亿                    │
│    skill: 阈值监控 · 实时                     │
│    ✅ 启用 · 距阈值 +8 亿                      │
└──────────────────────────────────────────────┘
```

**新建策略走 NL → DSL**:

```
用户输入:"光模块板块每天 9:35 跑龙头识别,综合分变化超 0.05 提醒我"
       ↓ LLM
DSL 草稿(YAML):
  trigger: cron "35 9 * * 1-5"
  skill: leader_identification
  subject: { sector: BK_CPO }
  condition: leader_score.composite changed_by >= 0.05
       ↓
可视化卡片 + 编辑入口 → 用户确认 → 落库启用
```

**策略详情页**:历史命中列表、最近一次 Artifact 预览、命中分布趋势、暂停/启用开关。

### 6.2 Skill 库

系统内置 + 用户启用的所有 Skill。每个 Skill 卡片显示:

- 名称、描述、输入/输出 schema 摘要。
- 启用状态(影响 chat 是否能调用)。
- 被多少策略引用、最近一次调用时间。
- "在 Chat 中试用" 按钮(预填一个示例 input)。

### 6.3 Agent 形态(第一阶段)

**第一阶段 = 规则驱动 + NL 转规则**:

- 用户描述需求 → LLM 转 DSL → 可视化确认 → 系统按规则跑。
- 不引入"目标驱动"的自主 Agent;所有触发条件、命中逻辑、输出动作都是显式定义的。

**远期演进(目标驱动 Agent)**:

- 用户设目标("持续盯着光模块,有重要变化告诉我"),AI 自主决定调什么 Skill、什么算"重要"。
- 引入"目标 → 监控计划 → 自适应调整"的反馈循环。
- 需要 LLM 判断力 + 较强的成本控制;非第一阶段范围。

## 7. 全局元素

### 7.1 铃铛 Notification Bell

- 顶栏右上角图标,数字徽标显示未读高优先级提醒数。
- 点击展开抽屉,列出最近 N 条高优先级提醒。
- 跨页面工作——不依赖在主页才能看到。
- 点击单条:行为同主页要点(进 chat thread 或全屏 Artifact)。

### 7.2 全局命令栏(Cmd+K)

研究场景下用户经常带着具体上下文跳转。Cmd+K 提供:

- 搜索 subject(板块/个股/事件)→ 直接跳分析页。
- 搜索历史 Artifact → 直接跳 Artifact 视图。
- 触发"快速提问"→ 在 Chat 新建 thread。

### 7.3 数据时效性标记

- 每个数据点有 `as_of` 时间戳,UI 用统一规范展示("日终" / "实时" / "T-1")。
- 盘中盘后顶栏右侧有市场状态指示(如"沪深开盘中 / 美股盘前 / 商品休市")。

## 8. 技术选型

| 维度 | 选型 | 备注 |
|---|---|---|
| 框架 | Next.js 16(App Router)+ React 19 | 默认 RSC |
| UI | shadcn/ui + Tailwind v4 | 设计系统统一 |
| 表格 / 趋势 | ECharts | 数值密集图表 |
| 产业链图 / 跨市场影响图 | Cytoscape.js | 关系图谱 |
| 服务端状态 | TanStack Query | 所有 API 数据 |
| UI 状态 | Zustand | 偏好、过滤器、最近浏览 |
| 前后端契约 | REST + OpenAPI 自动生成 TS 客户端 | |
| 工程化 | pnpm + ESLint flat + Prettier + Vitest + Playwright | |

**状态边界**:服务器数据全 TanStack Query;Zustand 只管 UI 偏好(thread 折叠状态、关注列表本地缓存、表格列宽等)。

**路由设计**:

```
/                            → 主页
/chat                        → Chat(默认最后一个 thread)
/chat/{thread_id}            → 指定 thread
/analysis/market             → 分析-大盘
/analysis/sector/{id}        → 分析-板块
/analysis/stock/{code}       → 分析-个股
/analysis/event/{id}         → 分析-事件
/strategy                    → 策略-我的策略
/strategy/skills             → 策略-Skill 库
/strategy/{id}               → 策略详情
/artifacts/{run_id}          → Artifact 全屏视图
```

## 9. 多端

- **第一阶段**:Web 桌面端为主,移动端响应式只读(主页 + 铃铛 + 简化 Chat)。
- **机器人**(飞书 / 电报):仅承载提醒推送和轻量问答;深度研究引导用户回 Web。
- **远期**:原生移动 App(如果用户需求强烈)。
